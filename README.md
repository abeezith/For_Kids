# ATL Explorer — Practice Lab

An interactive Class 6 practice resource for school-level Atal Tinkering Lab selection.

## Included

- A guided 38-minute ATL crash course
- 100 questions across five skill areas
- 20 balanced questions in each attempt
- A different question set for consecutive attempts
- Practice and exam modes
- Answer explanations and category-wise results
- Mobile-friendly, offline-compatible design

The quiz is an independent practice resource based on publicly available Atal Innovation Mission curriculum themes. It is not an official AIM/NITI Aayog examination.
